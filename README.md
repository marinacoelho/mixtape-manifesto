# Mixtape

Mixtape is a chat app. I know what you're thinking: "_another chat app?!_" Yes, but this one is different - **it is purely meant for sharing links to songs**, and it will automatically convert the link from one music platform to another. We currently support conversions from Spotify links to Apple Music links and vice versa. 

Now you can share your favorite songs with your friends, even if they're not using the same music platform as you!
